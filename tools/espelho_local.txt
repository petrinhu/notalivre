# Espelho local do CI (R2, achado A0-02; L-36). Uma linha por job do ci.yml: NOME DO JOB NO CI | COMANDO LOCAL.
# Os nomes são os do GitHub (matriz expandida). tools/espelho/comparar_jobs.py confere esta lista contra os jobs
# do ci.yml e contra os nomes do último run empurrado. Executar tudo: tools/espelho/rodar_espelho.sh.
# Cada comando roda o próprio trabalho dentro de contêiner (L-50) e roda na trava única ~/.claude/bin/pesado (L-11, item 2).
