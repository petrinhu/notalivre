# NotaLivre

O NotaLivre é um aplicativo para Linux que serve para emitir Nota Fiscal de Serviço eletrônica (NFS-e) pelo Sistema Nacional NFS-e, o sistema oficial do governo para essas notas. O objetivo é que você consiga emitir, consultar, cancelar e substituir notas sem pagar por um sistema comercial.

O app é pensado para MEI, autônomos e pequenas empresas do Simples Nacional. Escritórios contábeis ficam fora da primeira versão.

## Estado atual

Em desenvolvimento. Ainda não emite notas.

O app não tem versão para uso. Quando a primeira versão estiver pronta, a entrega planejada é um pacote Flatpak para Linux.
